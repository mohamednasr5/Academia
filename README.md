# أكاديمية مركز شباب الأحمدية لكرة القدم ⚽🦅

المنصة الرسمية وتطبيق الويب التقدمي (PWA) لأكاديمية كرة القدم بمركز شباب الأحمدية —
موقع عام متكامل + لوحة تحكم إدارية شاملة، مبنية بـ **HTML + CSS + JavaScript**
(بدون خطوة بناء) ومتكاملة مع **Firebase Realtime Database** للتخزين السحابي.

---

## ✨ ما الجديد في الإصدار 3.0 (إعادة تصميم وتطوير)

- **هوية بصرية فاخرة جديدة** — هوية "ليل الملعب": قاعدة خضراء داكنة + ليمون كهربائي
  رياضي + ذهب البطولات للإنجازات، مع تصميم متجاوب 100% وتأثيرات حركية أنيقة.
- **لوحة تحكم إدارية شاملة** — نظرة عامة (إحصائيات + نشاط أخير)، إدارة كاملة لكل
  اللاعبين والمدربين والبطولات والمباريات والأخبار وجدول التدريب ونجم اليوم.
- **رفع الصور فعلياً** — نظام مركزي لرفع صور اللاعبين والمدربين والأخبار والكؤوس
  والشعار، مع ضغط تلقائي وحفظ في قاعدة البيانات (بدون روابط مكسورة).
- **دليل لاعبين متقدم** — بحث + فلترة حسب الفئة السنية والمركز + بطاقة تفاصيل لكل
  لاعب (تاريخ ميلاد، عمر، مركز، قدم مفضلة، حالة تسجيل، إنجازات، أداء، إحصائيات).
- **مركز مباريات احترافي** — لوحات نتائج بأسلوب سكوربورد، مباريات قادمة وسابقة،
  مسجلو الأهداف، تقارير المباريات.
- **إعدادات عامة** — تحكم في اسم الأكاديمية والشعار والتواصل وروابط التواصل
  الاجتماعي والإعلانات المنشورة، وتغيير رمز المرور الإداري.
- **تحويل الطلبات إلى لاعبين** — قبول/رفض طلبات التقديم، تواصل واتساب فوري، وتحويل
  الطلب المقبول إلى بطاقة لاعب مسجل بدون تكرار.
- **أمان محسّن** — مصادقة بكلمة مرور مُجزّأة (SHA-256) وجلسة منتهية الصلاحية.
- **PWA كامل** — أيقونات حقيقية، Service Worker باستراتيجية تخزين ذكية، إشعار تحديث.
- **SEO كامل** — Open Graph، Twitter Cards، بيانات منظمة (JSON-LD)، sitemap، robots.txt.

## 🔐 بيانات دخول لوحة التحكم

- **رابط لوحة التحكم**: افتح `admin.html` أو انقر زر **"لوحة التحكم"** أعلى الموقع.
- رمز المرور يُدار من داخل لوحة التحكم، ويُخزّن كقيمة مُجزّأة في إعدادات قاعدة البيانات؛ لا توجد كلمة مرور افتراضية منشورة في ملفات المشروع.
- بوابة تسجيل الدخول الحالية تعتمد على تحقق من جهة العميل؛ لا تعتبر بديلًا عن Firebase Authentication وقواعد أمان Realtime Database للتحقق والصلاحيات من جهة الخادم.

## 📤 الرفع على GitHub و GitHub Pages

1. أنشئ مستودعاً (أو استخدم المستودع الحالي `mohamednasr5/Academia`).
2. ارفع جميع ملفات المشروع:
   ```bash
   git add .
   git commit -m "Upgrade: premium redesign + full admin dashboard + image management"
   git push origin main
   ```
3. من إعدادات المستودع: **Settings → Pages** → اختر النشر من الفرع `main` (المجلد `/`).
4. سيعمل الموقع فوراً برابط مباشر: `https://<username>.github.io/Academia/`

> لأن الموقع يستخدم مسارات نسبية (`./`)، يعمل تلقائياً سواء على نطاق جذر أو مسار فرعي.

## 🔥 تكوين Firebase

المشروع مُعدّ مسبقاً بمشروع Firebase `academia-e6d7b`. الإعدادات في `js/firebase-config.js`
(هي إعدادات Firebase العامة الآمنة للعرض في الواجهة الأمامية — ليست أسراراً).

### قواعد أمان Realtime Database

لا تفعّل `.write: true` على قاعدة البيانات كاملة؛ فهذا يسمح لأي زائر بتعديل بيانات الأكاديمية أو حذفها. إعداد آمن مبدئي للقراءة العامة هو:

```json
{
  "rules": {
    ".read": true,
    ".write": false
  }
}
```

هذه القواعد تمنع الكتابة من المتصفح إلى أن نربط لوحة الإدارة بـ Firebase Authentication ونضع قواعد تسمح للمستخدم الإداري المصادق عليه فقط بالكتابة. رمز المرور المحلي الحالي لا يُعد مصادقة لدى Firebase.

```
academia/
├── index.html              # الموقع العام (كل الأقسام في صفحة واحدة)

├── article.html            # صفحة تفاصيل الخبر

├── sw.js                   # Service Worker

│   ├── style.css           # نظام التصميم العام

    ├── logo.jpg
    └── icons/              # أيقونات PWA (192/512/maskable/apple-touch/favicon)
```
