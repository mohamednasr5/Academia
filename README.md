# أكاديمية مركز شباب الأحمدية لكرة القدم ⚽🦅

المنصة الرسمية وتطبيق الويب التقدمي (PWA) لأكاديمية كرة القدم بمركز شباب الأحمدية.
تم تصميم وبرمجة المنصة بأعلى معايير الفخامة بهوية الشعار الملكي (الأسود الرخامي والذهب اللامع).

---

## 🌟 المميزات الرئيسية
1. **التعريف بالجهاز الفني والمدربين**: بطاقات تفصيلية تشمل (صورة المدرب، اسمه، سنه، مؤهلاته والرخص التدريبية، وسيرته الذاتية).
2. **شريط الأخبار المتحرك (Breaking News Ticker)**: شريط إخباري متحرك في أعلى الموقع يعرض جديد الأكاديمية والنتائج العاجلة.
3. **لوحة الشرف أو رجل اليوم (Player of the Day)**: اختيار نجم الأكاديمية المتميز للظهور في صدارة الموقع ببطاقة ذهبية فخمة وعد تنازلي مباشر لمدة 24 ساعة واحتفال التتويج (Confetti).
4. **دولاب البطولات والكؤوس**: استعراض سجل الإنجازات والكؤوس المحققة مع الأعوام والفئات السنية وشارات التتويج.
5. **مواعيد العمل والتدريب**: جداول الحصص التدريبية الأسبوعية مقسمة حسب الفئات العمرية والملاعب والمدرب المسؤول.
6. **المباريات القادمة ونتائج المباريات**: تبويب تفاعلي للمباريات المجدولة ومواعيدها وملاعبها، ولوحة لنتائج المباريات ومسجلي الأهداف.
7. **كتالوج ولاعبي الأكاديمية**: معرض صور اللاعبين، أسماؤهم، أعمارهم، مراكزهم، وأرقام القمصان مع فلترة سريعة حسب الفئة السنية.
8. **أخبار الأكاديمية**: تقارير ومقالات مصورة عن الفعاليات والمعسكرات.
9. **نموذج تقديم وتسجيل لاعب جديد**: استمارة متكاملة للتقديم مع حفظ فوري وإمكانية فتح محادثة واتساب فورية مع إدارة الأكاديمية لتأكيد الاختبار.
10. **لوحة تحكم إدارية شاملة (Admin Dashboard)**: متجاوبة 100% مع الهواتف الذكية مع شريط سفلي (Bottom Navigation Bar) لإدارة كامل محتوى المنصة.
11. **تطبيق ويب تقدمي (PWA)**: قابل للتثبيت كبرنامج مستقل على شاشة الهاتف والكمبيوتر مع دعم وضع عدم الاتصال (Offline Support).

---

## 🛠️ التقنيات المستخدمة
- **الواجهة الأمامية**: HTML5 + CSS3 + Vanilla JavaScript (ES6 Modules).
- **قاعدة البيانات والتخزين**: Firebase Firestore + LocalStorage Synchronization (يعمل أونلاين وأوفلاين).
- **الهوية البصرية**: تم دمج الشعار الرسمي في مجلد `images/` ليكون جاهزاً للرفع على مستودع GitHub.
- **التأثيرات والأيقونات**: Canvas Confetti + Google Fonts (Cairo & Tajawal).

## 🔐 بيانات دخول لوحة التحكم (Admin Panel)
- **رابط لوحة التحكم**: افتح ملف `admin.html` أو انقر على زر **"لوحة التحكم"** أعلى الموقع.
- **رمز المرور الافتراضي**: `ahmadia2026`

---

## 🚀 كيفية التشغيل والرفع على GitHub
1. **التشغيل المباشر**:
   - يمكنك فتح ملف `index.html` في أي متصفح، أو تشغيل خادم محلي عبر الأمر:
     ```bash
     python -m http.server 8080
     ```
     ثم فتح الرابط: `http://localhost:8080`
2. **الرفع على GitHub و GitHub Pages**:
   - قم برفع جميع ملفات المشروع إلى مستودعك على GitHub:
     ```bash
     git add .
     git commit -m "Initial commit for Academia Al-Ahmadia Platform"
     git push origin main
     ```
   - من إعدادات المستودع (Settings -> Pages) اختر النشر من الفرع `main` ليعمل الموقع مجاناً فوراً برابط مباشر!
